# 개발 로드맵

## 1단계: UI 기반 MVP

- 사용자 자격 프로필 요약
- LH·SH 및 지역 필터
- 공고 목록과 적합도 표시
- 관심 공고 저장 인터랙션
- 제출 서류 체크리스트
- 반응형 웹 화면

현재 구현된 단계다. 공고는 샘플 데이터로 표시한다.

## 2단계: 도메인 구조 분리

- 사용자, 공고, 공급 주택, 자격 규칙, 제출 서류 타입 정의
- 화면에서 샘플 데이터와 판정 로직 분리
- 자격 규칙 평가기를 순수 함수로 구현
- 판정 결과와 근거를 검증하는 단위 테스트 추가

## 3단계: 실제 공고 수집

- LH·SH 공식 데이터 제공 방식 조사
- API 또는 허용된 수집 방식으로 공고 동기화
- 공고 원문과 첨부 PDF 저장 및 버전 관리
- 정정 공고 감지와 중복 공고 병합
- 데이터 갱신 실패 및 품질 모니터링

## 4단계: 공고문 분석

- PDF 및 첨부 문서에서 공급 주택, 자격 기준, 일정, 서류 추출
- 추출 결과에 원문 페이지와 문구 근거 연결
- 자동 추출 결과에 대한 검수 상태 관리
- 모호하거나 충돌하는 규칙은 추가 확인 상태로 처리

## 5단계: 개인화 및 저장

- 사용자 로그인과 프로필 저장
- 관심 공고와 서류 준비 상태 저장
- 마감일 알림과 공고 변경 알림
- 개인정보 암호화, 보존 기간, 삭제 정책 적용

## 6단계: 서비스 확장

- 다른 지역 공사와 지자체 사업 추가
- 지도 기반 지역·단지 탐색
- 통근 시간 및 생활 편의 정보 결합
- 공고 간 비용과 자격 조건 비교
- 운영자용 수집·검수 대시보드 구축

## 우선 구현 권장 순서

실제 서비스 신뢰도를 위해 `도메인 구조 분리 → 공식 데이터 수집 → 근거가 있는 자격 판정 → 사용자 저장` 순으로 진행한다. 지도나 알림 같은 편의 기능보다 데이터 정확성과 판정 설명 가능성을 먼저 확보한다.
