# 프로젝트 개요

## 프로젝트명

RealEstate Helper — 내집레이더

## 목적

사용자의 나이, 거주지, 가구 구성, 소득, 자산, 무주택 여부 등의 조건을 바탕으로 LH·SH를 포함한 정부·공공기관의 주거지원 사업 중 신청 가능한 공고를 찾고, 지원 가능한 지역과 주택 정보 및 제출 서류를 한곳에서 정리하는 개인 맞춤형 웹 서비스다.

## 해결하려는 문제

공공주택 공고는 기관과 사업 유형별로 흩어져 있고, 자격 기준과 제출 서류가 복잡하다. 사용자는 여러 공고문을 직접 읽으면서 자신의 신청 가능 여부를 반복해서 판단해야 한다. 이 서비스는 다음 과정을 단순화한다.

1. 사용자 조건을 구조화한다.
2. 최신 공고와 자격 조건을 수집한다.
3. 신청 가능성 및 충족·미충족 근거를 계산한다.
4. 지역, 단지, 주택 유형, 비용, 일정 정보를 비교한다.
5. 공고별 제출 서류와 발급처를 체크리스트로 제공한다.

## 주요 사용자

- 청년·신혼부부·한부모 가구 등 공공주택 특별공급 대상자
- 행복주택, 국민임대, 매입임대, 전세임대 등을 탐색하는 무주택자
- 여러 기관의 공고와 준비 서류를 한 번에 관리하려는 사용자

## 현재 상태

현재 MVP에는 맞춤 결과 화면, 기관·지역 필터, 공고 카드, 자격 적합도, 관심 공고, 제출 서류 체크리스트가 구현되어 있다. 표시되는 공고와 금액은 UI 및 기능 검증용 샘플이며, 실제 LH·SH 공고 데이터 연동은 다음 단계에서 구현한다.

## 핵심 원칙

- 판정 결과보다 판정 근거를 중요하게 다룬다.
- 공고 원문을 최종 기준으로 삼는다.
- 데이터의 출처와 갱신 시점을 노출한다.
- 민감한 개인정보를 최소한으로 수집한다.
- 기관과 사업 유형을 추가하기 쉬운 구조를 유지한다.
