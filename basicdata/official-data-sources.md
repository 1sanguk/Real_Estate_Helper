# 공식 데이터 출처와 연동 원칙

## LH

- 분양임대공고문 조회 서비스: https://www.data.go.kr/data/15058530/openapi.do
- 공고별 공급정보 조회 서비스: https://www.data.go.kr/data/15056765/openapi.do
- 목록·공급·상세 API를 결합하고 원문 URL과 원본 응답을 보존한다.

## HUG

- 든든전세주택 모집공고 데이터: https://www.data.go.kr/data/15139525/fileData.do
- 공식 설명상 분기 갱신 데이터이며 모집일, 접수일, 지역, 면적, 보증금, 주택형태 정보를 제공한다.
- 활용신청으로 받은 실제 API 주소가 설정된 경우에만 수집한다.
- HUG 공식 안내에 따르면 든든전세는 무주택 여부를 심사하고 소득·자산은 심사하지 않는다: https://www.khug.or.kr/jeonse/web/s07/s070101.jsp

## SH

- 공개된 주택분양 정보: https://www.data.go.kr/data/15008820/fileData.do
- 이 자료는 중장기 공급계획이며 현재 접수 가능한 모집공고 목록이 아니다.
- 모집공고로 오인될 가능성이 있으므로 실제 공고 API 또는 기관이 허용한 연계 방식이 확인되기 전까지 자동 수집 대상에서 제외한다.

## 공통 원칙

- 합성 공고를 사용자 화면에 표시하지 않는다.
- 종료 공고는 보관할 수 있지만 홈 기본 목록과 자동 적합성 재계산에서는 제외한다.
- 자동 추출과 자동 판정은 근거를 함께 표시하고 공식 원문 확인 전까지 사전 진단으로 안내한다.
