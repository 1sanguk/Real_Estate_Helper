# 코드 재점검 결과

## 반영 사항

- 공고 테이블이 비어 있을 때 고정 공고를 표시하던 동작 제거.
- 화면에서 최신 프로필로 판정을 계산해 이전 배치 결과가 조건 수정을 덮어쓰지 않도록 변경.
- 관심 공고 전용 경로 `/saved`, 공고명·주소·사업 검색, 지역 필터, 가능성 필터 추가.
- 관심 저장 및 로그아웃 실패 안내, 저장 중 중복 클릭 방지 추가.
- 공고 조회의 로딩·오류·빈 결과 상태 분리.
- 무주택 정보 누락 시 추가 확인 처리, 공급 면적 누락을 0㎡로 변환하던 오류 수정.

## 추가 반영 사항

- 홈에는 `공고중`, `정정공고중`, `접수중`인 실제 공고만 기본 표시한다.
- 공고별 연령·무주택·지역·자산·자동차·소득 조건을 충족/미충족/확인 필요로 분리한다.
- 혼인 기간, 자녀·태아, 청약 납입 횟수, 해당 지역 거주 기간, 대학·취업준비 상태와 졸업 후 기간을 구조화해 프로필과 비교한다.
- 공고문에 가구원 수별 월평균소득 금액이 명시된 경우 사용자의 가구원 수와 월소득을 직접 비교한다.
- 신뢰도 80% 미만의 자동 추출 규칙은 부적격 판정에 사용하지 않고 확인 필요로 보낸다.
- 공고문 자동 분석 결과를 관리자가 검수하고 상태와 메모를 남기는 페이지를 추가했다.
- 신규 적합 공고와 관심 공고 마감 알림을 저장하고 사용자가 알림 여부를 설정할 수 있다.
- 회원 탈퇴 시 Supabase Auth 계정과 연결된 개인정보를 연쇄 삭제한다.
- 로그인 실패는 아이디와 접속 주소를 단방향 해시한 키로 집계하며 5회 실패 시 15분간 제한한다.
- 개인정보 처리 안내와 서비스 이용 안내 페이지, 회원가입 필수 동의를 추가했다.
- 자동 동기화 실패 시 관리자 내부 알림을 생성한다.
- 감사 로그의 변경 필드명은 유지하되 생년월일·소득·자산·자동차 가액은 값 자체를 저장하지 않는다.
- HUG 든든전세 공식 공공데이터를 변환하는 수집기를 추가했다.

## 외부 설정이 필요한 기능

- HUG 데이터는 공공데이터포털 데이터 15139525 활용신청 후 `HUG_LISTINGS_API_URL`과 공통 `PUBLIC_SERVICE_KEY`를 등록해야 실제 수집된다.
- SH에서 확인된 공개 주택분양 자료는 공급계획이며 실시간 모집공고가 아니다. 실제 모집공고 API 또는 허용된 연계 방식이 확보되기 전에는 공고 목록에 섞지 않는다.
- 이메일·문자 발송은 별도 발송 사업자 설정이 없으므로 현재 서비스 내부 알림으로 제공한다.
- 소득 비율 규칙은 추출하지만 가구원 수와 공급 유형별 공식 기준금액 표가 공고마다 달라 자동 확정하지 않고 `확인 필요`로 표시한다.

이전 로드맵의 단계별 설명은 계획이며, 외부 인증 또는 공식 데이터가 없는 기능을 완료된 것으로 표시하지 않는다.
