# 데이터 및 자격 판정 구조

## 주요 데이터 영역

### 사용자 프로필

개인 조건과 희망 조건을 관리한다. 주민등록번호, 계좌번호 등 판정에 불필요한 식별정보는 저장하지 않는다.

### 모집 공고

기관, 공고명, 사업 유형, 접수 기간, 공고 기준일, 원문 URL, 모집 상태, 공급 대상과 공통 유의 사항을 포함한다.

### 공급 주택

공고에 포함된 지역, 단지명, 주소, 주택 유형, 전용면적, 공급 수, 보증금, 임대료, 입주 예정일을 관리한다. 하나의 공고에 여러 주택이 포함될 수 있다.

### 자격 규칙

연령, 거주지, 무주택, 가구 구성, 소득, 자산, 재학·재직 상태, 우선순위 등의 조건을 규칙 단위로 표현한다. 규칙에는 적용 대상, 연산 방식, 기준값, 예외, 근거 문구와 공고 원문 위치를 저장한다.

### 제출 서류

서류명, 필수 여부, 적용 대상, 발급처, 유효기간, 제출 형식, 공고문 서식 URL을 관리한다.

## 권장 데이터 출처

- LH 청약플러스 및 LH 공식 모집 공고
- SH 인터넷청약시스템 및 서울주택도시공사 공식 공고
- 공공데이터포털에서 제공되는 관련 API
- 지자체 및 기타 공공주택 사업 시행기관의 공식 공고

실제 연동 전에는 각 사이트의 API 제공 여부, 이용약관, 로봇 정책, 재배포 가능 범위를 확인해야 한다.

## 자격 판정 결과 형식

판정 결과는 최소한 다음 정보를 포함한다.

- 최종 상태: 가능, 추가 확인, 어려움
- 충족한 조건 목록
- 충족하지 못한 조건 목록
- 판정할 수 없는 조건과 필요한 추가 정보
- 사용한 공고 기준일과 사용자 정보 기준일
- 각 조건의 공고문 근거
- 공식 원문 확인 링크

## 판정 시 주의 사항

- 소득·자산 기준은 연도, 가구원 수, 사업 유형에 따라 달라질 수 있다.
- 같은 사업명이라도 개별 공고에서 세부 기준이 달라질 수 있다.
- 모집 공고의 정정 공고가 게시되면 최신 버전을 우선해야 한다.
- 자동 판정은 신청 가능성을 돕는 도구이며 최종 자격을 보장하지 않는다.
- 확정적으로 계산할 수 없는 조건을 임의로 통과 처리하지 않는다.
